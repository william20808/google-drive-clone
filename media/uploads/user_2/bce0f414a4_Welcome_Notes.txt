Google Drive Clone - Welcome Notes
===================================

Welcome to your personal cloud storage application!

Key Capabilities:
- Zero-lag Theme Switcher (Light & Dark mode)
- File upload with drag-and-drop overlay
- Multi-format previews (PDF Reading Mode, Photo Zoom/Rotate, Video Player, CSV Table Viewer)
- Nested folder creation, renaming, and in-memory fast traversal
- Multi-item selection: star, move, trash, restore, delete, download as ZIP
- Public token sharing for both files and folder subtrees
- Quota and storage plan management (15GB, 100GB, 500GB)
